Invent a Word We Need: coin one new English word and define it in a single clear line.

The entry coins **Miswave** — waving at a stranger you mistook for a friend, then pretending you were stretching all along. A small daily embarrassment English has no word for, named in one line every reader recognises at once.

## Run it

```sh
node main.ts
```

The program writes the entry to `/output/entry.txt` (103 characters, one line).
